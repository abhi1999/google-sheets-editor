# Coach Demo — Cue Sheet

Pairs with `coach-demo.srt`. Record a silent screen capture, navigating live through the steps below in order; import the `.srt` into your editor (or YouTube/Loom) to burn the captions. These are minimum display times — linger at least that long on each screen, and nudge later timestamps in your editor if a click/modal takes longer in practice.

| # | Action while recording | Caption shown |
|---|---|---|
| 1 | Land on Home | Cricket Scouting App — Coach Walkthrough |
| 2 | Stay on Home | Three things today: tryout evaluations, team formation, and in-game tracking. |
| 3 | Click Tryout Evaluations | SECTION 1 — FOR COACHES |
| 4 | Point at batch dropdown | Players are grouped into batches. |
| 5 | Open the dropdown | Each batch shows its player count right in the dropdown. |
| 6 | Select a different batch | Switching batches instantly filters the board. |
| 7 | Open a player card | Every player is evaluated against a skill rubric. |
| 8 | Expand section "A" | Skills are grouped into lettered sections — A, B, C... |
| 9 | Click a star rating | Each skill is rated 1–5 stars, weighted by importance. |
| 10 | Type in a note box | You can leave a note on any skill. |
| 11 | Scroll to & expand Fitness Assessment | Fitness Assessment covers Yo-Yo, jump tests, and plank holds. |
| 12 | Click Save Evaluation | Save Evaluation locks it in. |
| 13 | Point at the Yo-Yo badge | Yo-Yo scores are color-coded automatically. |
| 14 | Hold on badge | Green = 15.5+, Amber = 15.2–15.49, Red = below 15.2. |
| 15 | Open Reports → All Fitness Scores | Shows up on the board, the player card, and here. |
| 16 | Reopen a player card, point at info strip | The card also shows self-declared profile and batting/bowling stats. |
| 17 | Point at the two tabs | Two tabs: My Evaluation, and All Coaches. |
| 18 | Click All Coaches tab | Every coach rates independently — compare scores side by side. |
| 19 | Open Reports dropdown | Reports roll all of this up. |
| 20 | Scroll the list | My Evals, Skill Notes, All Fitness Scores, Selection — one place for every view. |
| 21 | Open Team Packages | SECTION 2 — CREATING A TEAM PACKAGE |
| 22 | Show the slot grid | Each team gets 13 required slots, plus up to 3 reserves. |
| 23 | Drag a player into a slot | Assign players, then mark a Captain, Vice-Captain, and Wicketkeeper. |
| 24 | Point at Selected toggle on a player card | Admins can also mark a player Selected or Not Selected from their card. |
| 25 | Hold | That drives the Selected Players report. |
| 26 | — | Once finalized, an admin approves the package as the official roster. |
| 27 | Go Home → click In-Game Ratings | SECTION 3 — IN-GAME RATINGS & OPPORTUNITY METRICS |
| 28 | Pick a team + game number | Pick a team and a game number. |
| 29 | Click Rate on a player | Rate any player on that roster. |
| 30 | Show the rating form | Same rubric as tryouts — scoped to one game. |
| 31 | Point at the checkboxes | Checkboxes mark whether they actually batted or bowled that game. |
| 32 | Point at Catches Dropped + notes | Catches Dropped tracking and notes on every section, plus Overall. |
| 33 | Save, reopen Rate | Reopening Rate loads your last entry — it updates, not duplicates. |
| 34 | Open Opportunity Sheet, Edit mode | Tracks batting order, bowling order, overs, and who coached. |
| 35 | Switch to View mode | View mode shows every game for a team side by side. |
| 36 | Hold | One glance tells you if playing time is rotating fairly. |
| 37 | Back to Home | That's the coach-facing app: evaluate, select, track. |
| 38 | — | Admin tools — approvals, settings — coming in a separate walkthrough. |
